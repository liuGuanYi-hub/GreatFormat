# 知识库 05：番剧原声交互与 Web Audio 短音频平滑播放工程

## 📌 核心设计原则

1. **绝对不用劣质 AI 合成音**：用户体验的灵魂在于真实感与情感共鸣，全部采用《JOJO的奇妙冒险》官方动画/游戏正版声优原声（小野友树）；
2. **柔和舒适、绝不炸耳**：加入正弦平滑渐入渐出（S-Curve Fade-In / Fade-Out），保护用户听力；
3. **超短音频防截断保护**：针对 $\le 1.5$ 秒的短语音进行特殊防护。

---

## ⚠️ 踩坑记录：超短音频被提前淡出截断

### 1. 踩坑现象
东方仗助名台词 *「グレートだぜ…！」*（时长 1.1 秒）播放时几乎听不到声音。

### 2. 根因剖析
之前的播放控制器统一设置了 `380ms` 慢速淡入，并在 `audio.duration - audio.currentTime <= 0.42s` 时触发 `380ms` 淡出：
- 对于 1.1 秒的音频：第 0.38 秒刚达到最大音量，在第 0.68 秒就进入了淡出，导致声音刚起步就被静音截断！

---

## 🛠️ 最佳实践解决方案

1. **响度标准化（Loudnorm）**：
   使用 FFmpeg 对所有原声音频进行 EBU R128 标准化增益：
   ```bash
   ffmpeg -y -i raw.mp3 -af "volume=2.2,loudnorm=I=-14:TP=-1.0:LRA=9" -b:a 192k clean.mp3
   ```
2. **自适应极速渐入与自然收尾**：
   - 渐入时间缩短至 `120ms`（保证瞬时发声且消除爆音 Click）；
   - 音频自然播放至 `onended` 事件触发，不再人为在结尾强行提前掐断。\n
